# Запуск VIP TASK в Railway

Этот проект запускается как один веб-сервис FastAPI + Telegram-бот с polling. Основной интерфейс пользователей — Telegram Mini App.

## Что должно быть в Railway

1. Один сервис приложения из репозитория `artemka000222111/vip-task`.
2. Отдельный сервис PostgreSQL в том же Railway project.
3. Публичный HTTPS-домен для сервиса приложения.
4. Для Telegram polling оставь **один экземпляр приложения**. Не включай несколько реплик одного сервиса.

Railway должен собирать приложение по корневому `Dockerfile`. Не запускай `bot.py` отдельно: рабочая точка входа — `app:app`.

## Переменные приложения

Добавлять их нужно в Variables сервиса приложения. Секреты вводи непосредственно в Railway — не отправляй их в чат и не добавляй в GitHub.

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота, сохранённый в Railway |
| `DATABASE_URL` | Ссылка на переменную `DATABASE_URL` сервиса Railway PostgreSQL через Railway Reference |
| `WEBAPP_URL` | Публичный HTTPS-домен сервиса приложения, например `https://твой-домен.up.railway.app` |
| `ADMIN_IDS` | Необязательно: дополнительные Telegram ID администраторов через запятую. Главный администратор уже задан в коде |
| `TASK_PRICE_SOCIAL_NETWORK_KOPECKS` | Цена одного задания в социальной сети в копейках |
| `TASK_PRICE_YANDEX_BROWSER_KOPECKS` | Цена одного задания в Яндекс Браузере в копейках |
| `TASK_PRICE_YANDEX_MAPS_KOPECKS` | Цена одного задания в Яндекс Картах в копейках |

**Цены заданий пока не подставлены автоматически:** нужно указать все три переменные целыми числами в копейках. Например, 25 ₽ — это `2500`. Не указывай значения наугад. Доступны только задания в социальных сетях (TikTok, Instagram, YouTube, Telegram, VK), Яндекс Браузере и Яндекс Картах. Опросов и заданий на других сайтах нет.

`PORT` Railway задаёт автоматически. Вручную его добавлять не нужно.

## Проверка после запуска

1. Убедись, что деплой завершился без ошибок.
2. Открой `https://твой-домен/health`. Ожидаемый ответ: `{"status":"ok","database":"connected","telegram_bot":"running","expiration_worker":"running"}`.
3. Проверь, что `WEBAPP_URL` совпадает с HTTPS-доменом приложения.
4. Открой Telegram-бота и отправь `/start`.
5. Нажми «Открыть VIP TASK». Приложение должно открыться внутри Telegram.
6. Главный администратор тоже должен один раз открыть бота и нажать Start: бот отправляет ему скриншоты и подтверждения пополнений.
7. Проверь профиль, список заданий, создание заказа, кошелёк и админ-панель.

При первом запуске приложение само создаёт/обновляет таблицы PostgreSQL. Не подключай вместо Railway PostgreSQL старую базу и не удаляй старые резервные копии.

## Важные ограничения запуска

- Не запускай второй экземпляр бота с тем же токеном: polling должен работать только в одном экземпляре.
- Не публикуй `BOT_TOKEN` или `DATABASE_URL` в GitHub.
- Не считай ручную заявку на вывод выплаченной, пока деньги действительно не отправлены пользователю.
- Перед приёмом реальных пополнений и выплат сначала проверь сценарии на небольших тестовых суммах.
